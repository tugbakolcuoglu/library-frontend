# Library Frontend Project

Bu proje, staj sürecinde geliştirdiğim library-api backend projesine bağlı olarak oluşturulmuş frontend uygulamasıdır.

## Kullanılan Teknolojiler
- React
- TypeScript
- Vite
- Axios

## Proje İçeriği
- Kitap listeleme
- API üzerinden veri çekme
- Öğrenci detay sayfası

## Açıklama
Frontend tarafı VS Code kullanılarak geliştirilmiştir. Backend ile veri alışverişi sağlanarak dinamik içerik oluşturulmuştur. API'den veriler Axios kullanılarak çekilmiş ve kullanıcı arayüzünde görüntülenmiştir.
